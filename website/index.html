// Caratteristiche

🔒

Sicurezza di default

AppArmor, UFW, Fail2ban e ClamAV preinstallati e configurati. Firewall attivo dal primo avvio.

🕵️

Privacy al centro

Tor Browser, WireGuard, VeraCrypt e Firejail inclusi. Nessuna telemetria. DNS sicuri di default.

🔄

Auto-aggiornamento

Aggiornamenti di sicurezza automatici ogni notte. Comando sudo smart update per aggiornare tutto.

⚡

Leggero e veloce

Desktop MATE ottimizzato. Avvio rapido, basso consumo RAM. Ideale anche su hardware datato.

🎨

Identità originale

Tema dark FutureOS-Dark, icone Papirus, font Inter + JetBrains Mono. GRUB e Plymouth personalizzati.

🛠

Pentesting ready

Nmap, Wireshark, Aircrack-ng, John, Hydra e altri strumenti professionali preinstallati.

// Installazione

01

Scarica la ISO

Scarica l'immagine ISO da GitHub Releases o dal link download qui sotto.

02

Crea USB avviabile

sudo dd if=future-os-1.0.iso of=/dev/sdX bs=4M status=progress

03

Avvia dal USB

Riavvia il PC e avvia dal dispositivo USB. Seleziona "Live" per provare o "Install".

04

Installa

Apri il terminale e digita sudo future-os-install per avviare l'installer grafico.
